# 📘 ArkKB 使用手册

欢迎使用 ArkKB，一款极致轻量、极速响应的现代化知识库编辑器。

## 🚀 快速上手

### 1. 文件管理
- **浏览**：通过侧边栏快速切换项目文件。
- **搜索**：利用 Bluge 强力引擎进行全文检索（仅限 < 1MB 文件）。
- **软删除**：删除文件将移至 `~/.arkkb/trash/`，安全无忧。

### 2. 编辑与预览
- **智能编辑**：深度集成的 CodeMirror 6 提供丝滑的文本编辑体验。
- **代码增强**：支持 LSP 协议，享受自动补全与跳转（需配置相应语言服务）。
- **极速预览**：PDF、HTML 等格式通过原生内核零开销渲染。
- **外部唤醒**：二进制文件自动调用系统默认软件打开。

### 3. 数据安全
- **原子保存**：采用三段式原子落地技术，确保在断电等极端情况下文件不损坏、不丢档。
- **自动同步**：窗口重获焦点时自动比对文件变动，保持索引最新。

## ⌨️ 快捷键
- `Ctrl + S`：安全保存当前文件。
- `Ctrl + P`：快速搜索文件。
- `Ctrl + F`：在当前文件中查找。

---
*ArkKB - 宁可功能降级，也绝不在关键路径上做 $O(N)$ 运算。*
