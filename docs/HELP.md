# ArkKB Help

ArkKB 是一个本地化、轻量化的工作台，用来管理真实文件系统、多根工作区和虚拟归档。

## 工作区

- `Ctrl+O` 打开或切换工作区。
- 左侧 `Workspace` 面板支持多根目录；`添加根目录` 会把新目录并入当前工作区。
- `Use` 设为当前活动根目录，`Default` 设为默认创建目标。

## 新建与归档

- `新建文件` / `新建目录` 始终创建真实文件系统对象。
- `新建归档` 创建逻辑虚拟文件夹，不会在磁盘上生成同名目录。
- 在 `Virtual` 面板中：
  - `新建文件` 会把文件创建到默认目标目录，然后自动挂入当前归档。
  - `归档当前文件` 会把当前标签页对应的真实文件挂入当前归档。
- 归档会记住最近一次使用的根目录和父目录，后续新建会优先落到这个位置。

## 归档浏览

- 左侧归档区仍保留紧凑态入口。
- 当选中自动分类或手动归档后，可以点击 `展开浏览` 进入主工作区浏览台。
- 展开态支持：
  - `分类 / 归档 / 目录` 三个导航标签
  - `快找 / 内容` 两种检索模式
  - `列表 / 首字母 / 目录 / 类型` 四种分组视图
  - 名称、最近修改、最近打开、类型、目录排序
- 文件交互规则：
  - 单击只切换右侧预览
  - 双击或 `Enter` 才打开正式标签页
  - 上下方向键会移动当前选中项并同步预览

## 检索

- 顶部搜索面板支持按文件名、路径和已索引正文搜索。
- 搜索结果会优先排序：
  - 当前活动根目录
  - 当前归档
  - 最近打开项
  - 白名单目录和白名单文件类型
- 大于策略阈值的文件只建立基础索引，不做全文分词。

## 规则策略

设置面板支持四类规则：

- `Directory Allowlist`
- `Directory Blocklist`
- `File Type Allowlist`
- `File Type Blocklist`

规则行为：

- 黑名单是硬过滤，不进入默认树和默认索引。
- 白名单是软优先，会提升搜索排序和默认新建目标优先级。

## 编辑与预览

- 文本文件由 CodeMirror 接管。
- Markdown 可在编辑 / 预览之间切换。
- 图片、PDF、HTML 走原生预览。
- 二进制文件通过系统默认应用打开。
- 归档展开态右侧预览会优先展示当前选中文件，不支持预览时会显示元信息和外部打开入口。

## 快捷键

- `Ctrl+O` 切换工作区
- `Ctrl+P` 打开搜索面板
- `Ctrl+S` 保存当前文件
- `Ctrl+B` 显示 / 隐藏侧栏
- `Ctrl+,` 打开设置

## 说明

- 帮助文档优先来自内置 embedded docs，离线可用。
- LSP 目前只保留外部可执行路径配置，不负责自动安装语言服务。
